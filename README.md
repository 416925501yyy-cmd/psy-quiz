# 心理学刷题

给备考心理学硕士的人用的手机刷题工具。纯前端、零依赖、离线可用，**不需要注册、不需要服务器、不需要装 APP**。

当前题库：**普通心理学（230 题 / 14 章）+ 实验心理学（202 题 / 12 章）= 432 题**
题型覆盖单选、多选、判断、名词解释、简答，每道题都带解析。

---

## 一、怎么放到手机上（两条路，选一条）

> 想让她**在任何网络下都能用、不依赖你的电脑**，见 [`部署到网上.md`](部署到网上.md)。

### 方案 A：单文件版（最省事，推荐先试）

```bash
node tools/build.mjs
```

生成 `dist/心理学刷题-单文件版.html`。

把这**一个文件**通过微信「文件传输助手」、邮件或 QQ 传到手机，用手机的浏览器打开即可。
整个应用（包括 432 道题）都在这个文件里，断网也能刷。

> 手机上打开本地 HTML 的方式：
> - 安卓：微信收到文件 → 右上角「…」→「用其他应用打开」→ 选 Chrome / 夸克 / 系统浏览器
> - iPhone：存到「文件」App → 点击文件 → 用 Safari 打开

### 方案 B：局域网直连（不用上传，最快看到「APP 效果」）

电脑和手机连同一个 WiFi，然后在项目目录执行：

```bash
node tools/serve.mjs
```

终端会打印两个地址，手机浏览器打开那个 `http://192.168.x.x:5173` 的地址即可，
然后「添加到主屏幕」，桌面上就有图标了（电脑关掉服务器后，已缓存的内容仍能离线打开）。

> 想让应用一直可用、不依赖电脑，就用下面的方案 C。

### 方案 C：放到网上（可以「添加到主屏幕」，体验最像 APP 且长期可用）

把 `dist/site/` 整个目录上传到任意静态托管（GitHub Pages、Vercel、Netlify、Cloudflare Pages、对象存储都行），
拿到网址后用手机浏览器打开，然后：

- iPhone Safari：分享 → 「添加到主屏幕」
- 安卓 Chrome：菜单 → 「添加到主屏幕 / 安装应用」

之后桌面就有图标，点开是全屏无浏览器边框的，而且**离线可用**（Service Worker 缓存）。

在电脑上想先看看效果，可以在项目根目录跑：

```bash
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 二、功能

| 功能 | 说明 |
| --- | --- |
| 按科目 / 章节刷题 | 顺序刷或随机抽题，进度条 + 章节掌握度 |
| 题目导航（答题卡） | 答题页点右上角题号或宫格按钮，一屏看到全部题号，点哪去哪；支持「回到第 1 题」「跳到未做题」「最后一题」 |
| 每日一练 | 每天按「没做过 → 做错过 → 不稳定 → 已掌握」的优先级智能抽题，题量可调 |
| 错题本 | 做错自动收录，答对自动移出；也可手动清空 |
| 收藏 | 遇到重点随时点 ☆ |
| 背题模式 | 名词解释、简答先默背再对答案；也可一键全部展开 |
| 即时判题 | 选完立刻出对错和解析（可关掉，改成点「提交」） |
| 学习统计 | 正确率、章节掌握度、近 7/30 天题量、13 周打卡热力图、连续打卡天数 |
| 快捷键 | 电脑上 `←` `→` 切题，数字键 `1-8` 选答案，`Enter` 下一题；手机上左右滑动切题 |
| 深色模式 | 跟随系统 / 手动切换，字号四档可调 |
| 导入题库 | 粘贴文本或 JSON 就能加题，不用改代码 |
| 导出备份 | 一键导出做题记录 + 收藏 + 自建题库为 JSON，可换机恢复 |

所有数据存在手机浏览器的本地存储里，**不上传、不联网**。

## 三、导入自己的题（重要）

在「我的 → 导入题目」里粘贴。支持下面这种从 Word / PDF 整理出来的文本：

```
# 科目: 普通心理学
# 章节: 我的补充题

1. 下面哪个选项是心理学成为独立学科的标志？
A. 1879年冯特在莱比锡大学建立第一个心理学实验室
B. 1900年弗洛伊德提出精神分析
C. 1913年华生发表《行为主义者眼中的心理学》
D. 1956年米勒发表《神奇的数字7±2》
答案：A
解析：1879 年冯特建立第一个心理学实验室，标志科学心理学的诞生。

2. 短时记忆的容量约为 7±2 个组块。
答案：对
解析：米勒 1956 年提出，以组块为单位的短时记忆容量约 7±2。

名词解释：感觉阈限
答案：感觉阈限是指能可靠引起感觉的最小刺激量……

简答：简述注意的分配及其条件
答案：1）同时进行的活动至少有一种是熟练的……
```

解析规则：

- 题干以 `1.` `1、` `(1)` 开头，或用 `名词解释：` `简答：` `判断：` `多选：` 开头
- 选项以 `A.` `A、` `A)` 开头
- `答案：` 后写 `A` / `AB` / `对` / `错` / 参考答案文本
- `解析：` 后写解析（可选）
- `# 科目:` `# 章节:` 用来分组（可选，不写就用界面上选的默认值）

也支持 JSON：题目数组、`{subject, chapters}`、或整个 bank 数组。点「填入示例」可以先看看格式。

## 四、开发与维护

```
index.html              应用外壳
styles.css              样式（含深色模式）
app.js                  全部逻辑：路由、刷题引擎、存储、导入导出、统计
data/bank-general.js    题库 · 普通心理学
data/bank-experimental.js 题库 · 实验心理学
sw.js                   Service Worker（离线缓存，仅 http 下生效）
manifest.webmanifest    PWA 配置
icons/                  图标（SVG + PNG，PNG 由脚本生成）
tools/make-icons.mjs    重新生成 PNG 图标
tools/validate.mjs      题库自检（答案越界、空选项、题干重复等）
tools/smoke-test.mjs    功能冒烟测试（自带轻量 DOM 模拟，无需浏览器）
tools/serve.mjs         本地预览服务器（手机同 WiFi 可访问）
tools/build.mjs         打包成单文件版 + 站点目录
```

常用命令（也可以直接用 npm 脚本）：

```bash
npm test        # = 题库自检 + 功能冒烟测试（50 项）
npm run build   # 打包产出到 dist/
npm run serve   # 本地预览，手机同 WiFi 可直接访问
npm run icons   # 重新生成 PNG 图标

# 等价的手写命令
node tools/validate.mjs   # 改完题库先跑这个
node tools/make-icons.mjs # 图标需要重新生成时
node tools/build.mjs      # 打包产出到 dist/
node tools/smoke-test.mjs # 用轻量 DOM 模拟把整个应用跑一遍
```

### 题库字段说明

```js
{
  t: 'single',        // single 单选 | multiple 多选 | judge 判断 | term 名词解释 | short 简答 | essay 论述
  q: '题干',
  o: ['A 项', 'B 项', 'C 项', 'D 项'],   // 判断题和主观题不用写
  a: 0,               // 单选填序号（从 0 开始）；多选填 [0,2]；判断填 true/false；主观题填文本
  e: '解析',
  tag: ['高频']       // 可选，会显示成小标签
}
```

每道题的记录以「科目+章节+题干」的哈希作为 id，所以**在中间插入新题不会打乱已有做题记录**；
但**修改题干文字会让那道题的记录重置**。

## 五、关于题库内容

题库按经典教材体系编排：普通心理学参照彭聃龄《普通心理学》，实验心理学参照郭秀艳、朱滢《实验心理学》。

需要特别注意：**目前这套题是按通用考研大纲整理的，不是广外的历年真题**。
建议确认一下广外最新的自命题科目名称与参考书目（研招网 / 学院官网的招生目录），
如果指定了别的教材，用「导入题目」把真题和指定教材的题加进来即可，应用本身不用改。

导入前建议先跑 `node tools/validate.mjs`，它会检查答案越界、空选项、题干重复等问题。
